# Repository writing guidance

Apply these rules to prose written for this repository.

- Do not use Unicode em dashes or en dashes as sentence punctuation. Use an ASCII hyphen only when a dash is needed.
- Prefer periods, commas, conjunctions, or parentheses when they make a sentence clearer.
- Limit colons in normal prose. Rewrite label forms as complete sentences.
- Avoid semicolons in normal prose. Use a period or a comma with a suitable conjunction.
- Use straight double quotes in authored prose by default.
- Preserve source laws, transcriptions, generated data, structured syntax, citations, and URLs.
